界面定义要点（供讨论，非最终稿）

  • 一个新调度模式：不新开页面，在既有「新建定时任务」弹窗里加第 4 种模式，配置分四块——汇总范围、计划模板、审批策略、派发约束。
  • 待审批是一等队列：Scheduled 页签新增「待审批」入口并带角标；过期卡片保留可见（显示按什么策略处理了），不静默消失。
  • 审批粒度 = 计划里的每条任务：可单选、可改（改 Agent/工作区/提示词）、带风险标注；支持「低风险免审批」把确认成本降到接近零。
  • 通知是极简闭环：全部批准 / 挑选 / 跳过三个动作在通知上完成，不强制打开主窗口。
  • 回流是数据闭环的关键：审批产生的任务与其他会话同库记录，明天 8:30 的"昨日总结"才有的可查。
  • 待商榷：风险分级规则谁来定（模板内置 vs 用户标注）？超时默认跳过还是合并？审批后的派发是否也要允许"定时不审批"直跑变体？
