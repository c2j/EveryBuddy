# EvoBuddy icon and mascot assets

All files in this directory are **EvoBuddy's own artwork**, generated by
`gen_icons.py` from simple geometric primitives. They are not copied from
WorkBuddy, an icon theme, or any third-party icon set.

- License: the repository's MIT license (same as the host crate)
- Source: `gen_icons.py` (regenerate with `python3 crates/eb/assets/gen_icons.py`)
- Runtime: PNG bytes are embedded with `include_bytes!` in `src/icons.rs`; no
  icon theme, file path, or librsvg dependency is needed on any platform.
